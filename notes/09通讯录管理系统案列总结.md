# 通讯录管理系统（C++ 结构体 + 顺序表）笔记总结

> 目标：用 **结构体(struct)** + **数组顺序表** 实现一个命令行通讯录，支持增删改查与清空。  
> 核心思想：用 `m_Size` 表示当前有效联系人数量，把 `personArray` 当作“顺序表”。



## 1. 数据结构设计

### 1.1 联系人结构体 `person`

```cpp
struct person {
    string m_Name;     // 姓名
    int    m_Sex;      // 性别：1男 2女（用整型做枚举值）
    int    m_Age;      // 年龄
    string m_Phone;    // 电话（用 string 保存，避免前导0丢失/长度不固定/可能含+86等）
    string m_Address;  // 地址
};
````

**为什么电话用 `string`？**

* 电话不是用来做数学运算的；
* 可能有前导 0（如 010-xxxx），用 `int` 会丢 0；
* 可能包含 `+86`、`-`、空格等符号；
* 长度不固定（手机号/座机/分机/国际号）。

---

### 1.2 通讯录结构体 `phoneBook`

```cpp
#define max 1000

struct phoneBook {
    struct person personArray[max]; // 顺序表：固定容量数组
    int m_Size;                     // 当前有效联系人数量
};
```

**关键：`m_Size` 的意义**

* `m_Size` 表示当前已有多少个联系人；
* 下一个可写入的位置下标就是 `m_Size`；
* 有效数据范围：`[0, m_Size-1]`。

## 2. 菜单与主循环控制

### 2.1 菜单打印 `printMenu()`

输出功能列表：

* 1 添加联系人
* 2 显示联系人
* 3 删除联系人
* 4 查找联系人
* 5 修改联系人
* 6 清空联系人
* 0 退出

### 2.2 主函数 `main()`

```cpp
phoneBook abs;
abs.m_Size = 0;

while (true) {
    printMenu();
    cin >> select;
    switch(select) {
        case 1: addPerson(&abs); break;
        case 2: showPerson(&abs); break;
        case 3: deletePerson(&abs); break;
        case 4: findPerson(&abs); break;
        case 5: modefyPerson(&abs); break;
        case 6: cleanPerson(&abs); break;
        case 0: return 0;
    }
}
```

**特点**

* 用 `switch-case` 分发功能；
* 传入 `&abs`（地址传递），使函数能直接修改通讯录内容。

## 3. 添加联系人（增）

### 3.1 逻辑概述

* 先判断是否满：`m_Size == max`；
* 用 `m_Size` 定位新位置：`personArray[m_Size]`；
* 逐个写入姓名/性别/年龄/电话/地址；
* 添加成功后：`m_Size++`。

### 3.2 关键写法解释

```cpp
abs->personArray[abs->m_Size].m_Name = name;
```

**为什么是 `personArray[abs->m_Size]`？**

* `m_Size` 就是“当前最后一个有效元素的后面位置”；
* 每新增一个联系人都放在顺序表尾部；
* 写完后 `m_Size++`，保证下次继续在新的尾部追加。

### 3.3 性别输入校验（while true）

```cpp
while (true) {
    cin >> sex;
    if (sex == 1 || sex == 2) {
        abs->personArray[abs->m_Size].m_Sex = sex;
        break;
    }
    cout << "请输入正确的性别：" << endl;
}
```

## 4. 显示联系人（查全表）

### 4.1 空表判断

```cpp
if (abs->m_Size == 0) cout << "当前目录为空" << endl;
```

### 4.2 遍历输出

```cpp
for (int i = 0; i < abs->m_Size; i++) {
    cout << "姓名：" << abs->personArray[i].m_Name << "\t";
    cout << "性别：" << (abs->personArray[i].m_Sex == 1 ? "男" : "女") << "\t";
    cout << "年龄：" << abs->personArray[i].m_Age << "\t";
    cout << "号码：" << abs->personArray[i].m_Phone << "\t";
    cout << "地址：" << abs->personArray[i].m_Address << endl;
}
```

## 5. 查找工具函数（核心复用）

### 5.1 `isExist(phoneBook* abs, string name)`

* 顺序遍历查找姓名；
* 找到返回下标；
* 找不到返回 `-1`。

```cpp
int isExist(phoneBook* abs, string name) {
    for (int i = 0; i < abs->m_Size; i++) {
        if (abs->personArray[i].m_Name == name) return i;
    }
    return -1;
}
```

**意义**

* 为删除/查找/修改提供统一定位；
* 避免重复写查找逻辑。

---

## 6. 删除联系人（删）

### 6.1 删除思路：顺序表“覆盖前移”

* 用 `isExist` 找到目标下标 `ret`；
* 从 `ret` 开始，把后面元素依次向前覆盖：

  * `personArray[i] = personArray[i+1]`
* 最后 `m_Size--`，有效长度减 1。

```cpp
for (int i = ret; i < abs->m_Size - 1; i++) {
    abs->personArray[i] = abs->personArray[i + 1];
}
abs->m_Size--;
```

### 6.2 与 Python 列表删除的对比

* Python 的 `list.pop(i)` / `del` 本质也是“后元素前移”，只是底层帮你做了；
* C++ 用固定数组时必须手动移动数据；
* 这就是“顺序表删除”的典型实现。

---

## 7. 查找联系人（查单个）

* 输入姓名；
* `ret = isExist(...)`；
* `ret != -1` 则输出该联系人信息；
* 否则输出“查无此人”。

> 注意：输出对齐应使用 `"\t"`，而不是 `"/t"`。

---

## 8. 修改联系人（改）

* 输入要修改的姓名；
* 先定位下标 `ret`；
* 找到则重新输入并覆盖字段（姓名/性别/年龄/电话/地址）。

逻辑本质：**覆盖写入**。

---

## 9. 清空通讯录（清空）

```cpp
void cleanPerson(phoneBook* abs) {
    abs->m_Size = 0;
}
```

**为什么清空只需 `m_Size = 0`？**

* 顺序表有效数据只看 `[0, m_Size-1]`；
* `m_Size = 0` 代表“没有任何有效元素”；
* 原数组里的旧数据仍在内存里，但逻辑上已被视为无效（后续新增会覆盖掉）。

---

## 10. 本项目的核心知识点总结

1. **结构体建模**：用 `person` 表示联系人，用 `phoneBook` 管理联系人集合。
2. **顺序表思想**：固定数组 + `m_Size` 表示有效长度。
3. **尾插法添加**：写入 `personArray[m_Size]` 后 `m_Size++`。
4. **遍历展示**：for 循环输出 `[0, m_Size-1]`。
5. **顺序查找**：封装 `isExist` 返回下标或 -1。
6. **覆盖式删除**：后元素前移覆盖 + `m_Size--`。
7. **覆盖式修改**：定位到元素后重新赋值。
8. **逻辑清空**：`m_Size = 0` 即可完成清空。

---

## 11. 可改进点（建议）

* 输入健壮性：处理 `cin` 输入失败（非数字导致 fail 状态）。
* 删除逻辑：仅在找到联系人时才 `m_Size--`，避免误删或 size 变负。
* 输出格式：统一使用 `"\t"` 对齐。
* 宏命名：`max` 容易与 `std::max` 冲突，建议改为 `MAX_CONTACTS`（const int）。
* 地址/姓名含空格：可用 `getline` 支持空格输入。

## 12. 为什么这里不推荐用“值传递”（而用指针/引用传递）

在本通讯录项目中，`phoneBook` 内部包含：

- `personArray[max]`：一个容量最多 1000 的联系人数组  
- `m_Size`：当前有效联系人数量

如果把 `phoneBook` 作为函数参数用**值传递**（例如 `void addPerson(phoneBook abs)`），会带来一系列问题：


### 12.1 值传递会“拷贝一整份通讯录”，开销巨大

值传递会把整个 `phoneBook` **复制一份**传入函数。

- `phoneBook` 里有 `personArray[1000]`
- 每个 `person` 里还有多个 `string`
- `string` 的拷贝本身也可能涉及动态内存管理

结果就是：调用一次函数就可能触发大量拷贝，性能和时间开销明显增加。

> 本质：值传递 = 复制对象；对象越大，成本越高。

---

### 12.2 值传递修改的是“副本”，函数结束后修改全部丢失

通讯录的核心操作（添加、删除、修改、清空）都需要**改变原始通讯录**：

- 添加：`m_Size++`，并写入新联系人
- 删除：数据覆盖前移，`m_Size--`
- 修改：覆盖某个联系人字段
- 清空：`m_Size = 0`

如果用值传递，函数里改的是 **abs 的副本**，函数返回后原始通讯录不变：

```cpp
void addPerson(phoneBook abs) {  // 值传递：abs是副本
    abs.m_Size++;                // 改的是副本
}
// main里原来的abs.m_Size不变
````

这会导致：你“看起来添加成功了”，但回到主菜单再显示通讯录时，实际上没有变化。

---

### 12.3 值传递可能触发更复杂的拷贝/析构，增加潜在问题

`person` 内含 `string`，值传递会引发：

* 多次构造（copy constructor）
* 多次析构（destructor）
* 频繁的内存分配/释放

虽然现代 C++ 有优化（RVO/移动语义等），但**在参数传递上**仍然不建议对“大对象”使用值拷贝。

---

### 12.4 用指针/引用传递：性能更好、语义更正确

通讯录是一个“被管理的数据结构”，对它做操作本质是对同一个对象做增删改查。

因此更合理的写法是：

* **需要修改原对象**：传指针 `phoneBook*` 或引用 `phoneBook&`
* **只读不修改**：传 `const phoneBook*` 或 `const phoneBook&`

例如：

```cpp
void addPerson(phoneBook* abs);        // 修改
void showPerson(const phoneBook* abs); // 只读（可优化）
```

---

### 12.5 指针传递 vs 引用传递（本项目为何常用指针）

本项目使用指针（`phoneBook* abs`）的优点：

* 贴近 C 风格教学，便于理解“地址传递”
* 使用 `->` 明确表达“通过地址访问对象成员”
* 统一函数签名风格（全部传 `&abs`）

但从现代 C++ 风格来说，如果不考虑教学目的，更推荐：

* 修改：`void addPerson(phoneBook& abs)`
* 只读：`void showPerson(const phoneBook& abs)`

---

### 12.6 本项目的结论

**通讯录这种“大对象 + 需要修改”的场景：**

* 值传递 ❌（复制成本高 + 改副本无效）
* 指针/引用传递 ✅（无拷贝 + 直接改原对象）
