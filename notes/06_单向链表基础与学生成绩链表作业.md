## 2. 数组和链表的区别

数组在内存中通常是连续存放的：

```cpp
int a[5] = {10, 20, 30, 40, 50};
```

可以理解为：

```text
[10] [20] [30] [40] [50]
```

数组靠下标访问：

```cpp
a[0]
a[1]
a[2]
```

链表不是靠连续内存存放，而是靠指针串起来：

```text
head
 ↓
[10 | next] -> [20 | next] -> [30 | nullptr]
```

链表每个结点里除了数据，还要保存下一个结点的地址。

| 对比点 | 数组 | 链表 |
|---|---|---|
| 存储位置 | 连续 | 不一定连续 |
| 访问方式 | 通过下标直接访问 | 从 head 开始顺着 next 找 |
| 插入删除 | 可能要移动元素 | 主要改指针 |
| 查找第几个元素 | 快 | 要一个一个走 |
| 大小 | 通常较固定 | 可以动态增删 |

## 3. 结点 Node 是什么

链表由一个个结点组成。

一个最简单的结点：

```cpp
struct Node {
    int data;
    Node* next;
};
```

可以画成：

```text
[ data | next ]
```

其中：

```text
data：数据域，保存真正的数据
next：指针域，保存下一个结点的地址
```

为什么 `next` 是 `Node*`？

因为 `next` 指向的是下一个 `Node` 类型的结点，所以它的类型应该是 `Node*`。

例如：

```cpp
Node a;
Node b;

a.data = 10;
b.data = 20;

a.next = &b;
b.next = nullptr;
```

图像是：

```text
a                    b
[10 | &b] --------> [20 | nullptr]
```

## 4. head、next、nullptr 的含义

### 4.1 head：链表入口

链表必须有一个入口，一般叫 `head`。

```cpp
Node* head = nullptr;
```

`head` 保存第一个结点的地址。

```text
head
 ↓
[10] -> [20] -> [30] -> nullptr
```

如果 `head` 丢了，整条链表就找不到了。

### 4.2 空链表

如果链表里一个结点都没有：

```cpp
head = nullptr;
```

图像：

```text
head -> nullptr
```

判断空链表：

```cpp
if (head == nullptr) {
    return;
}
```

### 4.3 尾结点

最后一个结点叫尾结点。

```text
head
 ↓
[10] -> [20] -> [30] -> nullptr
```

这里 `[30]` 是尾结点，因为它的 `next` 是 `nullptr`。

链表结束的标志是：

```cpp
p == nullptr
```

或者某个结点是最后一个：

```cpp
p->next == nullptr
```

## 5. new 出来的结点和指针变量名的关系

初学时容易误解：

```cpp
Node* newNode = new Node;
```

这里 `newNode` 不是结点的名字，而是一个指针变量名。

`new Node` 每执行一次，都会在内存里申请一个新的结点，地址通常不同。

例如：

```cpp
Node* newNode = new Node;
newNode->data = 10;
newNode->next = head;
head = newNode;

newNode = new Node;
newNode->data = 20;
newNode->next = head;
head = newNode;
```

虽然都叫 `newNode`，但两次 `new Node` 创建的是两个不同结点。

第一次插入后：

```text
head
 ↓
[10 | nullptr]
```

第二次插入后：

```text
head
 ↓
[20 | next] -> [10 | nullptr]
```

只要第一次创建的结点已经被 `head` 或其他结点的 `next` 接住，后面让 `newNode` 改指向新结点就没有问题。

错误情况：

```cpp
Node* newNode = new Node;
newNode->data = 10;

newNode = new Node;
newNode->data = 20;
```

这里第一个 `[10]` 没有接入链表，也没有被其他指针保存地址，就丢了，造成内存泄漏。

规则：

```text
newNode 可以重复使用；
但每次重新指向新空间前，原来的空间要么已经接进链表，要么已经 delete。
```

## 6. 前插法：作业最核心的插入方式

前插法就是每次把新结点插到链表最前面。

核心代码：

```cpp
newNode->next = head;
head = newNode;
```

假设原来链表是：

```text
head
 ↓
[10 | nullptr]
```

现在插入 `20`。

先创建新结点：

```cpp
Node* newNode = new Node;
newNode->data = 20;
```

第一步：让新结点接住原来的链表。

```cpp
newNode->next = head;
```

图像：

```text
newNode
   ↓
 [20 | next] -> [10 | nullptr]
                  ↑
                 head
```

第二步：让 `head` 指向新结点。

```cpp
head = newNode;
```

最终：

```text
head
 ↓
[20 | next] -> [10 | nullptr]
```

所以依次前插：

```text
10 20 30
```

最后链表顺序是：

```text
30 -> 20 -> 10
```

前插法特点：

```text
后输入的数据排在前面。
```

顺序不能反。

错误写法：

```cpp
head = newNode;
newNode->next = head;
```

这样会让新结点自己指向自己，原来的链表可能丢失。

## 7. 遍历链表

遍历链表就是从 `head` 开始，一个结点一个结点往后走。

```cpp
Node* p = head;

while (p != nullptr) {
    cout << p->data << endl;
    p = p->next;
}
```

为什么不用 `head` 自己走？

错误倾向：

```cpp
while (head != nullptr) {
    cout << head->data << endl;
    head = head->next;
}
```

这样虽然能输出，但最后 `head` 会变成 `nullptr`，链表入口丢失。

所以遍历时应该用临时指针：

```cpp
Node* p = head;
```

记忆：

```text
head 负责守门；
p 负责跑路。
```

## 8. 删除结点

删除链表结点，不是简单把数据清空，而是改指针关系，让链表绕过这个结点，然后 `delete` 释放它。

### 8.1 删除中间结点

假设链表：

```text
head
 ↓
[30] -> [20] -> [10] -> nullptr
```

要删除 `20`。

需要两个指针：

```text
prev       cur
 ↓          ↓
[30] ---> [20] ---> [10]
```

核心代码：

```cpp
prev->next = cur->next;
delete cur;
```

执行后：

```text
[30] -> [10]
```

### 8.2 为什么删除需要 prev 和 cur

如果只知道当前结点 `cur`，无法修改前一个结点的 `next`。

删除当前结点，本质上要修改前一个结点：

```cpp
prev->next = cur->next;
```

所以：

```text
cur：当前检查的结点
prev：cur 前面的结点
```

### 8.3 删除头结点

如果要删除的是头结点，没有 `prev`，要单独处理。

```cpp
if (head->id == id) {
    Node* p = head;
    head = head->next;
    delete p;
    return;
}
```

一定要写 `return`。

如果不写 `return`，当链表原来只有一个结点时，删除后 `head == nullptr`，后面再执行：

```cpp
Node* cur = head->next;
```

就会访问空指针，程序出错。

### 8.4 删除非头结点

```cpp
Node* prev = head;
Node* cur = head->next;

while (cur != nullptr) {
    if (cur->id == id) {
        prev->next = cur->next;
        delete cur;
        return;
    } else {
        prev = cur;
        cur = cur->next;
    }
}
```

这里 `else` 可以写，也更适合初学者理解：

```text
找到了就删除并结束；
没找到就继续往后走。
```

删除后不能继续使用 `cur`，因为 `delete cur;` 后，`cur` 指向的空间已经被释放了。

## 9. 析构函数释放链表

链表中的每个结点都是 `new Node` 申请出来的，所以最后必须一个一个 `delete`。

```cpp
~StudentScoreList() {
    while (head != nullptr) {
        Node* p = head;
        head = head->next;
        delete p;
    }
}
```

逻辑：

```text
1. p 保存当前头结点
2. head 往后移动
3. delete p 释放旧头结点
4. 重复直到 head == nullptr
```

因为结点是用：

```cpp
new Node
```

申请的单个结点，所以释放时用：

```cpp
delete p;
```

不是：

```cpp
delete[] p;
```

## 10. 类封装版本：学生成绩链表

文件名建议：

```text
StudentScoreList.cpp
```

完整基础版本：

```cpp
#include <iostream>
using namespace std;

class StudentScoreList {
private:
    struct Node {
        int id;
        int score;
        Node* next;
    };

    Node* head;

public:
    StudentScoreList() {
        head = nullptr;
    }

    void insertStudent(int id, int score) {
        Node* newNode = new Node;
        newNode->id = id;
        newNode->score = score;
        newNode->next = head;
        head = newNode;
    }

    void showList() {
        Node* p = head;
        while (p != nullptr) {
            cout << "学号：" << p->id << " " << "成绩：" << p->score << endl;
            p = p->next;
        }
    }

    void deleteById(int id) {
        if (head == nullptr) {
            return;
        }

        if (head->id == id) {
            Node* p = head;
            head = head->next;
            delete p;
            return;
        }

        Node* prev = head;
        Node* cur = head->next;

        while (cur != nullptr) {
            if (cur->id == id) {
                prev->next = cur->next;
                delete cur;
                return;
            } else {
                prev = cur;
                cur = cur->next;
            }
        }
    }

    void deleteByScore(int score) {
        if (head == nullptr) {
            return;
        }

        if (head->score == score) {
            Node* p = head;
            head = head->next;
            delete p;
            return;
        }

        Node* prev = head;
        Node* cur = head->next;

        while (cur != nullptr) {
            if (cur->score == score) {
                prev->next = cur->next;
                delete cur;
                return;
            } else {
                prev = cur;
                cur = cur->next;
            }
        }
    }

    ~StudentScoreList() {
        while (head != nullptr) {
            Node* p = head;
            head = head->next;
            delete p;
        }
    }
};

int main() {
    StudentScoreList list;

    int id, score;
    int n;

    cout << "请输入学生人数：" << endl;
    cin >> n;

    for (int i = 0; i < n; i++) {
        cout << "请输入第" << i + 1 << "个学生的学号和成绩：" << endl;
        cin >> id >> score;
        list.insertStudent(id, score);
    }

    cout << "当前学生成绩链表为：" << endl;
    list.showList();

    cout << "请输入要删除的学生学号：" << endl;
    cin >> id;
    list.deleteById(id);

    cout << "按学号删除后的链表为：" << endl;
    list.showList();

    cout << "请输入要删除的成绩：" << endl;
    cin >> score;
    list.deleteByScore(score);

    cout << "按成绩删除后的链表为：" << endl;
    list.showList();

    return 0;
}
```

说明：

如果依次输入：

```text
1001 90
1002 80
1003 95
```

因为使用前插法，输出顺序会是：

```text
1003 95
1002 80
1001 90
```

这是正常现象，不是错误。

## 11. 命名建议

比较规范的命名：

| 用途 | 推荐命名 | 说明 |
|---|---|---|
| 文件名 | `StudentScoreList.cpp` | 学生成绩链表 |
| 类名 | `StudentScoreList` | 类名用大驼峰 |
| 结点结构体 | `Node` | 结构体名首字母大写 |
| 头指针 | `head` | 链表入口 |
| 新结点指针 | `newNode` | 指向刚 new 出来的结点 |
| 前驱指针 | `prev` | previous 的缩写 |
| 当前指针 | `cur` | current 的缩写 |
| 插入函数 | `insertStudent` | 插入学生成绩 |
| 遍历函数 | `showList` | 显示链表 |
| 按学号删除 | `deleteById` | 根据学号删除 |
| 按成绩删除 | `deleteByScore` | 根据成绩删除 |

如果想保留自己原来的简单风格，也可以用：

```cpp
class scoreList
struct node
void insert()
void show()
void deleteId()
void deleteScore()
```

但从规范性看，更推荐大写类名和结构体名。

## 12. 高频易错点

### 12.1 删除头结点后忘记 return

错误倾向：

```cpp
if (head->id == id) {
    Node* p = head;
    head = head->next;
    delete p;
}

Node* prev = head;
Node* cur = head->next;
```

如果链表只有一个结点，删除后 `head == nullptr`，再访问 `head->next` 会出错。

正确：

```cpp
if (head->id == id) {
    Node* p = head;
    head = head->next;
    delete p;
    return;
}
```

### 12.2 遍历时直接移动 head

错误倾向：

```cpp
while (head != nullptr) {
    cout << head->id << endl;
    head = head->next;
}
```

这样会丢失链表入口。

正确：

```cpp
Node* p = head;
while (p != nullptr) {
    cout << p->id << endl;
    p = p->next;
}
```

### 12.3 前插顺序写反

错误：

```cpp
head = newNode;
newNode->next = head;
```

正确：

```cpp
newNode->next = head;
head = newNode;
```

### 12.4 delete 后继续用 cur

错误倾向：

```cpp
if (cur->id == id) {
    prev->next = cur->next;
    delete cur;
}
cur = cur->next; // 错误：cur 已经被释放
```

正确：

```cpp
if (cur->id == id) {
    prev->next = cur->next;
    delete cur;
    return;
}
```

### 12.5 new 出来的结点没有接入链表就换指向

错误：

```cpp
Node* newNode = new Node;
newNode->data = 10;

newNode = new Node;
newNode->data = 20;
```

第一个结点地址丢失，造成内存泄漏。

正确思路：

```cpp
Node* newNode = new Node;
newNode->data = 10;
newNode->next = head;
head = newNode;
```

## 13. 最后背诵版总结

1. 链表由一个个结点组成，每个结点包含数据域和指针域。
2. `Node* next` 表示指向下一个结点的指针。
3. `head` 是链表入口，保存第一个结点的地址。
4. `head == nullptr` 表示空链表。
5. 尾结点的 `next == nullptr`。
6. `new Node` 每执行一次都会创建一个新的结点。
7. `newNode` 只是指针变量名，不是结点本身的名字。
8. 前插法核心是 `newNode->next = head; head = newNode;`。
9. 前插法会让后输入的数据排在前面。
10. 遍历时用临时指针 `p`，不要直接移动 `head`。
11. 删除头结点要单独处理，并且删除后要 `return`。
12. 删除非头结点需要 `prev` 和 `cur` 两个指针。
13. 删除中间结点的核心是 `prev->next = cur->next; delete cur;`。
14. `delete cur;` 后不能再访问 `cur` 指向的内容。
15. 析构函数中要循环释放整条链表，避免内存泄漏。
